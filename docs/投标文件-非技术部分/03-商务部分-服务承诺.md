# （四）服务承诺

致：郑州数据集团有限公司

河南卓康电子科技有限公司（以下简称"我方"）已认真研究了郑州数据集团有限公司房屋管理系统人力服务采购项目招标文件的全部内容，充分理解本项目"研发团队驻场开发+6年运维服务"的人力服务采购性质，以及房屋管理系统（含移动端、小程序端、微信公众号端、后台管理）建设内容与郑好办用户体系、港区支付接口、人脸识别接口等对接要求。若我方有幸中标，我方郑重作出如下服务承诺，并保证在合同履行全过程中严格兑现。本服务承诺构成我方投标文件的组成部分，中标后自动转为合同附件，对我方具有法律约束力。

## 一、服从调配安排承诺

1.**无条件服从统一调配。** 我方承诺项目团队全体人员在合同履行期间无条件服从招标人的统一调度、调配与安排。驻场人员的工作时间严格按照招标人员工的通常工作时间执行，办公地点服从招标人指定；招标人因业务需要临时调整工作时间、工作地点、工作内容的，我方人员在接到通知后立即响应执行，不讲条件、不打折扣。

2.**弹性加班保障。** 遇系统上线、版本发布、重要节点保障（如集中选房、集中缴费高峰期、重要检查评估等）需要加班加点的，我方人员服从招标人安排，主动加班保障，加班费用已包含在投标报价中，不再向招标人另行主张任何费用。

3.**任务优先级服从安排。** 开发任务的排期、优先级由招标人确定，我方按照招标人确认的开发计划组织实施；招标人对需求优先级进行调整的，我方在24小时内完成开发计划的相应调整并反馈书面调整结果。

4.**人员岗位动态调配。** 在项目各阶段之间（需求、开发、测试、试运行、运维），我方根据工作量变化及招标人要求动态增减、调配人员岗位；若合同约定的人月数内未完成合同规定的成果交付，我方承诺继续无偿安排人员投入，确保合同规定成果如期交付，由此产生的一切费用由我方自行承担。

5.**管理制度服从。** 我方驻场人员严格遵守招标人的考勤管理、门禁管理、保密管理、机房管理、网络安全管理等各项规章制度，接受招标人的日常管理与考核；考核结果与我方内部绩效直接挂钩。

## 二、全力协同招标人推进项目实施承诺

1.**专班推进机制。** 中标后我方立即成立由公司管理层挂帅的项目保障专班，项目负责人为第一责任人，公司层面开辟绿色通道，人、财、物资源优先向本项目倾斜，确保项目建设与招标人的总体信息化部署同频推进。

2.**主动汇报机制。** 我方建立"日沟通、周例会、月总结"工作机制：每日通过工作群同步开发进展；每周向招标人提交书面周报并召开项目例会，汇报本周完成情况、下周计划、风险与问题；每月提交月度总结报告。重大事项、重大风险第一时间专项汇报，绝不隐瞒、拖延。

3.**第三方协同配合。** 本项目涉及郑好办用户体系对接、港区支付接口对接、人脸识别接口调用、政务数据接口（社保、婚姻、学历、住房、保租房信息）调取等多方协作事项，我方承诺主动对接各相关单位与平台方，牵头组织联调测试，全过程做好接口文档、联调记录的整理归档；协调过程中遇到困难的，及时提请招标人协调，但绝不以第三方原因为借口拖延项目进度。

4.**需求变更快速响应。** 对招标人在项目实施过程中提出的合理需求变更与优化建议，我方按照"先响应、后评估、再确认"的原则处理：一般性调整48小时内给出评估结论并纳入开发计划；涉及重大变更的，5个工作日内提交书面变更评估报告供招标人决策。

5.**配合监督检查。** 我方无条件配合招标人及其上级单位、审计、监管部门对项目实施情况的监督、检查、审计工作，如实提供项目资料，对提出的整改意见在限期内完成整改并书面反馈。

6.**知识转移与培训协同。** 我方承诺在项目实施过程中同步开展知识转移，向招标人指定人员提供系统操作培训、管理端使用培训、常见问题处置培训，并提交操作手册、维护手册等培训材料，确保招标人相关人员能够独立完成日常业务操作。

## 三、服务人员及时到场到位承诺

1.**中标即到场。** 我方承诺在收到中标通知书并签订合同后**3个工作日内**，项目负责人及首批驻场人员进场开展工作；**7个工作日内**项目团队全部核心成员到岗到位，完成开发环境搭建并启动需求调研。

2.**驻场常态到位。** 我方承诺按投标文件所附《项目驻场人员承诺函》约定的人数派驻驻场人员，驻场人员在服务期内按招标人作息时间常态化在岗，不迟到、不早退、不脱岗；驻场人员名单报招标人备案，接受招标人考勤管理。

3.**紧急到场时限。** 运维服务期内，遇突发故障或紧急任务：

| 情形 | 响应方式 | 到场/响应时限 |
|:-----|:---------|:-------------|
| 一般咨询与问题 | 热线电话、网络支持、邮件报送 | 7×24小时随时响应，2小时内答复 |
| 一般性故障 | 远程处理为主 | 30分钟内响应，4小时内解决 |
| 影响业务办理的重要故障 | 远程+现场 | 15分钟内响应，驻场人员立即处置，需增援的2小时内到达现场 |
| 系统瘫痪、数据异常等重大故障 | 现场应急处置 | 10分钟内响应，郑州市区内1小时内技术骨干到达现场，恢复前不撤离 |

4.**关键节点驻点保障。** 在系统上线切换、集中选房、集中缴费、年度续租高峰等关键业务节点，我方提前制定专项保障方案，增派人员现场值守，实行7×24小时驻点保障，确保业务不中断。

5.**人员替补机制。** 驻场人员因病、事假等原因无法到岗的，我方于当日安排具备同等及以上能力的人员顶岗，确保岗位服务不断档；未经招标人书面同意，我方不擅自更换项目核心技术人员；确需更换的，替换人员资历不低于原人员，并提前5个工作日报招标人书面认可，交接期不少于5个工作日且交接期间双人在岗，费用由我方承担。

## 四、在岗人员恪尽职守履职承诺

1.**持证合格上岗。** 我方派驻本项目的全部人员均为与我方签订正式劳动合同并由我方缴纳社会保险的正式员工，具备本项目实施及维护服务所需的技能和资质，经招标人认可后方才上岗；上岗前完成保密教育、安全教育和岗位培训。

2.**廉洁从业。** 我方在岗人员严格遵守廉洁从业规定，不接受任何可能影响公正履职的宴请、礼品、礼金，不利用工作便利谋取私利；发现违规行为的，我方立即将当事人调离项目并按公司制度严肃处理，同时书面向招标人报告。

3.**保密履职。** 我方全体项目人员与我方签订保密协议，对在项目实施过程中接触到的招标人业务数据、租户个人信息（含身份信息、人脸信息、合同信息、缴费信息等）、系统架构与安全信息等严格保密，不复制、不外传、不用于合同目的之外的任何用途；保密义务不因合同期满或人员离岗而免除。违反保密义务的，我方承担全部法律责任。

4.**规范作业。** 在岗人员严格执行开发规范、测试规范、变更管理规范和操作规程，生产环境的任何变更操作均履行"申请—审批—备份—实施—验证"流程，杜绝违规操作、带病上线；重要操作留痕可溯。

5.**日志与交付物管理。** 驻场人员如实填写工作日志，按节点提交需求文档、设计文档、测试报告、上线报告、运维记录等交付物，文档资料真实、完整、及时归档，全部成果（含源代码）知识产权按合同约定归属招标人。

6.**服务态度。** 在岗人员做到服务主动、态度诚恳、用语文明，对招标人业务部门提出的问题耐心解答；招标人对我方人员服务态度或服务能力提出异议的，我方24小时内核实处理，确不胜任的立即无条件更换。

5.**人员违约。** 我方未经招标人同意擅自更换核心技术人员、驻场人员长期缺岗脱岗的，按合同约定承担违约责任；我方人员违反保密、廉洁规定给招标人造成损失或不良影响的，我方承担全部责任并赔偿损失。

1.**6年运维服务承诺。** 自系统最终验收合格之日起，我方提供为期**6年**的运维服务，运维费用已包含在投标总报价中，运维期内不再向招标人收取任何额外费用。运维服务范围包括但不限于：

- 系统日常巡检与健康状态监测（应用服务、数据库、中间件、接口服务）；
- 故障受理、诊断、修复与回访闭环管理；
- 系统缺陷修复与补丁升级、安全漏洞修复；
- 与郑好办、港区支付、人脸识别等外部接口的联通性监测与对接维护；

- 业务高峰期专项保障与重大活动值守；

3.**定期巡检与报告。** 运维期内每周开展例行巡检，每月提交运维月报（含系统运行情况、故障统计、处理情况、优化建议），每年提交年度运维总结报告及下一年度运维计划，供招标人考核评估。

4.**数据安全保障。** 严格执行数据备份策略（每日增量、每周全量），定期开展恢复性验证演练；对租户个人敏感信息（身份证、人脸数据、支付数据）按国家个人信息保护相关法律法规及等级保护要求落实加密存储、脱敏展示、权限管控与审计追踪，确保数据不丢失、不泄露。

5.**应急保障。** 中标后30日内编制并提交《系统应急预案》，覆盖系统瘫痪、数据损坏、网络攻击、支付异常等场景，明确应急组织、处置流程与恢复时限，每年至少组织1次应急演练；发生重大故障时启动应急预案，第一时间恢复业务，事后5个工作日内提交故障分析报告与整改措施。

6.**升级与持续改进。** 运维期内因国家政策调整、上级平台接口变更（如郑好办、港区支付接口升级）导致的系统适应性调整，我方无偿完成；对系统运行中发现的功能缺陷免费修复；持续收集用户反馈，每季度向招标人提交系统优化建议。

7.**期满移交承诺。** 运维服务期满或合同终止时，我方无条件配合招标人完成系统、数据、文档、源代码及相关资料的完整移交，提供不少于3个月的移交过渡期支持，协助后续服务单位平稳接管，绝不以任何形式设置技术壁垒或索取额外费用。
