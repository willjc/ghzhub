# 小功能拆分外发 · 速记

## 选什么
**只选门面页 / 静态页 / 错误页**：登录页、404、注册页、关于我们、用户协议、帮助中心。
禁止碰业务逻辑、禁止碰接口。

## 给什么（3 个东西）
1. 需求说明书（1 份 md）
2. 要改的原文件（1~3 个 .vue）
3. 打包 ZIP 发过去

## 文档写什么（就 4 段）
1. **任务**：精修（已有雏形）还是 重做（默认样式）
2. **必须保留**：列出 data / methods / v-model 字段名
3. **视觉要求**：色值、圆角、阴影，写具体数值
4. **验收**：4 种屏宽（1920/1440/1280/768）正常

## 怎么说话
- 不写"外包 / 承包 / 发包"
- 用"项目 / 任务 / 需求方 / 开发方"
- 不写时间费用（线下谈）

## 安全底线
- ❌ 不给完整源码
- ❌ 不给 .env / vue.config.js / api 目录
- ❌ 不给 Git 仓库访问权
- ✅ 让他们用开源若依/脚手架自己起空壳

## 一句话交代
> "包里有说明书 + 要改的 N 个文件。用开源若依起个空壳把文件替换进去做，做完发改过的单文件回来。"
