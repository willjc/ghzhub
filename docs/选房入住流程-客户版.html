港好住 · 选房入住完整流程

面向租户的小程序操作链路（客户简版）

步骤1

选择项目

用户登录小程序后，在首页/人才公寓/保租房/市场租赁等栏目中浏览项目列表，点击感兴趣的项目卡片进入「项目详情页」，查看项目介绍、户型、租金、配套等信息。

步骤2

资格校验（点击「选择房源」时触发）

系统自动判断用户身份并完成校验：

  • 批量配租用户：管理员已为其分配房源，免校验直接放行；
  • 普通用户：系统自动调取政务数据校验社保、学历、工作等信息；
  • 校验未通过 → 跳出失败页，告知未通过原因，流程终止；
  • 校验通过 → 进入下一步签署承诺书。
步骤3

签署租住承诺书

资格通过后，用户阅读项目相关的租住承诺书内容，勾选「我已阅读并同意」，并完成电子签字，作为正式入场的承诺凭证。

步骤4

选定具体房源（10 分钟锁房）

进入房源列表，仅展示该项目下的空置房源，已被预订/出租/维修/下架的均不显示。

用户选定某套房源后，系统立即原子锁定：

  • 该房源对其他人立即不可见，避免「同一套被多人定到」；
  • 开启 10 分钟倒计时，必须在此期间完成签合同。
⏱ 10 分钟内未签合同，房源自动释放回空置状态
步骤5

签订电子合同（e签宝）

系统按合同模板自动生成租赁合同（含租户、房源、租期、租金、押金条款）：

  • 平台甲方一侧自动盖章；
  • 用户跳转 e签宝完成实名认证 + 手写签字；
  • 双方签署完成后，合同状态变为「已签署」，自动跳转押金支付页。
步骤6

缴纳押金

用户在线支付押金，押金账单标记为「已缴」，房源状态由「已预订」变更为「已出租」。

  • 批量配租用户：到此订单完结，可直接进入步骤 8 办理入住；
  • 普通用户：进入「待上传材料」状态，开启 72 小时上传倒计时。
步骤7

上传审核材料（仅普通用户）

用户在 72 小时内上传两类必交材料：

  • 📄 工作证明
  • 🎓 学历证明（毕业证或在读证明）。

提交后由后台管理员逐份审核：

  • 通过 → 材料状态置为「已通过」；
  • 拒绝 → 必须填写拒绝原因，用户需在 72 小时内重新上传；
  • 两份均通过 → 订单自动流转为「已完成」。
⏱ 72 小时内材料未全部审核通过，订单将过期
步骤8

办理入住

订单进入「已完成」状态后，用户可申请入住。系统会先做前置自检：

  • 合同是否已签署 ✓
  • 押金是否已缴 ✓
  • 首期房租是否已缴 ✓

通过后用户填写实际入住日期、室友信息、紧急联系人等，提交入住申请；管理员核对后生成入住单 → 现场设施确认 → 合同正式进入「履行中」状态，整个流程闭环。

⚠️ 异常情况自动兜底

场景系统处理
选房 10 分钟内未签合同订单作废，房源自动释放回「空置」
签合同后未及时缴押金订单过期，房源释放
72 小时内材料未通过审核订单过期，房源释放，可重新选房
用户主动取消订单订单标记取消，房源即时释放
租住期间退租经审核扣费后退还押金，房源回到「空置」继续上架
