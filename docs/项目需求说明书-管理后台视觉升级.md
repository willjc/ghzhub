## 🎯 任务一：管理后台登录页 视觉精修

### 1.1 背景

原文件路径：`ruoyi-ui/src/views/login.vue`  
**当前状态**：已有左右分栏品牌化雏形（左侧品牌展示 60%、右侧登录表单 40%），但视觉粗糙：品牌区装饰仅为几个彩色圆圈、缺插画、排版单调、登录按钮无微交互。**本任务是视觉精修，不是重做**。

### 1.2 任务目标

在保留现有 DOM 结构与业务逻辑的前提下，完成以下视觉升级：

1. **左侧品牌区升级**：替换粗糙圆圈装饰，改用**航空港区 + 人才公寓主题**的 SVG 插画或装饰图案，整体质感向政务蓝大屏风格靠拢
2. **主副标题排版优化**：主标题加字重层次（目前只是 h1 + p），可加一条品牌金分割线、英文副标
3. **右侧表单区精修**：圆角、阴影、输入框 focus 态、按钮渐变色+hover 上浮 2px
4. **版权信息**：在右侧表单底部加一行版权（`© 2024-2026 郑州航空港区大数据管理局 · 技术支持 XXX`）
5. **响应式**：窗口 < 1200px 时左侧品牌区隐藏，登录表单居中全屏显示

### 1.3 必须保留（❌ 不得改动）

```js
// data 中这些字段名和结构必须完全保留：
loginForm: { username, password, rememberMe, code, uuid }
loginRules: { username, password, code }
captchaEnabled, register, redirect, codeUrl, loading, title

// methods 中这些方法必须完全保留：
getCode(), getCookie(), handleLogin()

// 所有 import 语句（getCodeImg / Cookies / vuex mapXxx 等）原样保留
// v-model 绑定全部原样保留
// @click / @keyup 事件绑定原样保留
```

### 1.4 视觉要求

| 区块 | 要求 |
|---|---|
| 左侧品牌区 | 政务蓝主色渐变背景 `#1E6FFF → #0A4ACC`；叠加半透明光斑或几何线条作为装饰；可放一张航空港区简化剪影 SVG |
| 主标题 | "港好住" 36px · 粗体 · 白色，下方 "人才住房智慧管理平台" 16px |
| 品牌金分割线 | 40px 宽 · 3px 高 · `#FFB800` · 主副标题之间 |
| 右侧登录卡 | 白底 · 圆角 8px · 阴影 `0 10px 40px rgba(0,0,0,0.08)` · 内边距 48px |
| 输入框 | 高度 48px · focus 时边框 `#1E6FFF` + 轻微外发光 |
| 登录按钮 | 高度 48px · 渐变色 · hover 上浮 2px 阴影加深 · 文字字间距 4px |
| 验证码图 | 圆角 4px · 光标 pointer · hover 微亮 |

### 1.5 验收清单

- [ ] 账号、密码、验证码、记住密码、登录按钮 **功能全部正常**
- [ ] 立即注册跳转正常（`register=true` 时显示）

## 🎯 任务二：管理后台 404 / 401 错误页 重做

### 2.1 背景

原文件路径：
- `ruoyi-ui/src/views/error/404.vue`
- `ruoyi-ui/src/views/error/401.vue`

**当前状态**：沿用若依默认 "云朵 + 数字 404" 卡通样式（见 `404_images/404.png`、`404_cloud.png`），与政务项目气质不符，需**整体重做**。

### 2.2 任务目标

重做两张错误页，统一风格为**政务简约插画风**，主色调采用港好住品牌色。

### 2.3 功能要求（不可遗漏）

| 页面 | 必须保留的元素 |
|---|---|
| `404.vue` | 大号 "404" 文案 + 标题 + 描述 + **"返回首页"按钮**（`router-link to="/"`）+ 保留 props `message`（默认值可改为 "页面走丢了"） |
| `401.vue` | 大号 "401" 文案 + "无访问权限" 描述 + **"返回登录"按钮**（`router-link to="/login"`） |

### 2.4 视觉要求

| 项 | 要求 |
|---|---|
| 布局 | 全屏居中（flex），背景用 `#F5F7FA` 或淡品牌蓝渐变 |
| 插画 | 左侧或上方放一张原创 SVG 插画：**城市剪影 + 迷路的小人 / 锁头图标**（404 用前者，401 用后者）；禁止使用网络现成有版权的图 |
| 数字 | "404" / "401" 用 120px 超大字号，品牌金 `#FFB800` 带轻微描边或渐变 |
| 标题 | 24px 深灰 `#303133`，加粗 |
| 描述 | 14px 次灰 `#909399`，限 1~2 行 |
| 按钮 | 主色渐变按钮，圆角 24px（胶囊），padding 12px 32px |
| 动画 | 数字或插画加轻微浮动动画（`@keyframes float` 2s 无限循环） |

### 2.5 禁止项

- ❌ 不得使用原 `404_images/404.png`、`404_cloud.png` 云朵图
- ❌ 不得引入任何 lottie-web、图标字体库等新依赖
- ❌ 插画必须是 **原创 SVG**（内嵌在组件里 或 独立 .svg 文件），不得使用网图

### 2.6 验收清单

- [ ] 直接访问不存在的路由能正常显示 404 页
- [ ] 无权限访问能正常显示 401 页
- [ ] "返回首页"、"返回登录" 按钮跳转正常
- [ ] 浏览器 tab 标题正确
- [ ] 1920 / 1440 / 1280 / 768 四种宽度均居中显示
- [ ] `props.message` 传入不同文案时正常显示
