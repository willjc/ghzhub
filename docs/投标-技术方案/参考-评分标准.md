# 参考：技术部分评分标准（总53分，缺漏项得0分）

> 摘自招标文件第三章评标办法 2.2.3（3）技术部分评分标准。
> 每项评分档：①内容完整、详实可行、科学合理、符合项目特点及要求，具有较强针对性 → 高档；②内容完整、详实可行、具有针对性 → 中档；③内容基本完整，具有一定可行性 → 低档。
> **注：技术部分各分项内容如缺漏项，相应分项得0分。**

## 1. 项目需求分析（9分）
评审点（5项，缺一不可）：
- [ ] 项目建设背景
- [ ] 建设内容
- [ ] 解析项目建设重难点
- [ ] 项目业务需求
- [ ] 应用功能需求

## 2. 应用系统功能设计（9分）
评审点（6项描述详尽度）：
- [ ] 应用系统功能执行标准
- [ ] 系统组成
- [ ] 系统结构
- [ ] 系统支撑
- [ ] 系统接口
- [ ] 系统安全

## 3. 项目实施管理（9分）
评审点（对系统开发、平台对接、运行测试、验收全流程管控）：
- [ ] 人员配置
- [ ] 开发规划
- [ ] 开发测试与协作管理
- [ ] 配置与变更管理
- [ ] 技术规范管控
- [ ] 部署对接及运行测试保障
- [ ] 低成本、标准化实现系统互联互通

## 4. 系统安全管理（9分）
评审点（安全解决方案）：
- [ ] 系统漏洞风险防控
- [ ] 病毒风险防控
- [ ] 黑客攻击风险防控
- [ ] 管理制度缺陷风险防控
- [ ] 适配信息系统安全技术、安全管理、二级等保要求的各项安全控制措施

## 5. 系统运维管理（9分）
评审点（11子项，一个不能少）：
- [ ] 系统部署升级
- [ ] 运维制度
- [ ] 运维技术工具
- [ ] 服务响应
- [ ] 运维范围
- [ ] 指标考核
- [ ] 日常维护
- [ ] 故障应急处置
- [ ] 系统及软件运行保障
- [ ] 人员配置
- [ ] 数据备份

## 6. 服务期限保证（8分）
评审点（项目服务期限计划涵盖）：
- [ ] 定制化开发
- [ ] 部署实施
- [ ] 技术对接
- [ ] 测试培训
- [ ] 上线验收

## 招标硬性参数（写作锚点）
- 开发期：**60日历天**，研发服务总人月数**不少于37人月**（自甲方书面开工通知起算）
- 软件免费运维期：**6年**（自最终验收合格之日起）
- 服务期限：自合同签订生效之日起至运维服务期结束
- 故障响应时限（招标文件运维要求）：**紧急10分钟、一般2小时**；远程服务7×24小时响应（热线电话、网络支持、邮件报送）
- 驻场要求：甲方指定地点办公、按甲方考勤、周运维报送、月度运维报告（每月末前2个工作日报送）、故障处理记录台账
- 驻场人员技术要求：3年以上系统运维及管理工作经验、独立承担任务与进度把控能力、良好沟通与服务意识、常态化培训用户
- 付款节点：签合同后25% → 驻场研发功能初验后50% → 终验后95% → 5%运维保证金（免费运维期满后结算）
- 源代码交付：可独立编译生成与生产环境一致的可执行文件、结构清晰注释完整、含编译部署脚本及说明文档
- 质量标准：合格，符合国家、行业相关合格质量标准及招标人要求
