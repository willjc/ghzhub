## 简介

本文档详细介绍了移动端H5入住退租接口的完整实现方案。该系统提供了完整的入住办理、退租申请、共同居住人管理等入住相关API接口，涵盖了从入住申请提交、入住材料审核、入住费用结算到退租申请处理、退租费用计算的核心业务流程。

**重要更新** 新增了管理员强制退租接口和退租审批系统快捷填入审批意见功能，通过"同意"一键操作简化了审批流程，提升了运营效率。管理员强制退租接口支持无需用户确认的一步式退租流程，直接完成合同终止和房源释放，适用于紧急退租场景。该功能支持在审批对话框中快速填入标准审批意见，减少了重复输入工作，同时确保审批意见的规范性和一致性。

系统采用前后端分离架构，前端使用UniApp框架开发H5应用，后端基于Spring Boot构建RESTful API服务。整个系统支持完整的业务流程控制、状态管理和数据一致性保障，并具备智能退款计算、入住状态检查、倒计时提醒、房屋状态自动释放、按日精算退租租金计算、租户姓名过滤、审批意见快捷填入等高级功能。

## 项目结构

### 前端架构
- **API层**: 提供统一的HTTP请求封装，包含入住、退租、共同居住人、退款等业务接口
- **页面层**: 基于Vue.js的单页应用，提供用户友好的交互界面
- **工具层**: 包含文件上传、请求拦截、权限验证等通用功能

### 后端架构
- **控制器层**: 处理HTTP请求，实现业务逻辑
- **服务层**: 封装核心业务逻辑，提供事务管理
- **数据访问层**: 基于MyBatis-Plus实现数据持久化
- **领域模型**: 定义业务实体和数据结构

```java
@Override
@Transactional
public int adminForceCheckout(Long contractId, String checkoutReason) {
    // 1. 查询合同信息
    HzContract contract = contractMapper.selectById(contractId);
    if (contract == null) {
        throw new ServiceException("合同不存在");
    }
    // 校验合同状态必须为已签署(2)或履行中(3)
    if (!"2".equals(contract.getContractStatus()) && !"3".equals(contract.getContractStatus())) {
        throw new ServiceException("该合同状态不允许退租");
    }

    String adminUser = SecurityUtils.getUsername();
    Date now = new Date();

    // 2. 创建退租申请记录（审计留痕），直接设为已完成
    HzCheckoutApply apply = new HzCheckoutApply();
    apply.setContractId(contractId);
    apply.setTenantId(contract.getTenantId());
    apply.setHouseId(contract.getHouseId());
    apply.setApplyTime(now);
    apply.setPlanCheckoutDate(now);
    apply.setCheckoutReason(checkoutReason);
    apply.setApplyStatus("5"); // 直接已完成
    apply.setApproveBy(adminUser);
    apply.setApproveTime(now);
    apply.setApproveOpinion("管理员直接退租");
    apply.setCreateBy(adminUser);
    apply.setDelFlag("0");
    checkoutApplyMapper.insert(apply);

    // 3. 更新合同状态为"已解约"
    contract.setContractStatus("5");
    contract.setUpdater(adminUser);
    contract.setUpdateTime(now);
    contractMapper.updateById(contract);

    // 4. 释放房屋状态为"空置"
    houseMapper.releaseHouseStatus(contract.getHouseId());

    return 1;
}
```

## 故障排除指南

### 常见问题及解决方案

#### 入住申请相关问题
1. **合同状态异常**
   - 检查合同是否处于已签署或履行中状态
   - 验证押金和首期租金是否已完全支付
   - 确认实际入住日期是否在允许范围内

2. **用户权限问题**
   - 验证用户是否已完善个人信息
   - 检查用户是否具有相应的租户身份
   - 确认用户是否已登录有效状态

#### 退租申请相关问题
1. **续租合同处理**
   - 检查合同是否已续租，押金是否已转移至续租合同
   - 验证用户是否从最新合同发起退租
   - 确认原合同状态是否已更新

2. **费用计算异常**
   - 检查账单状态是否正常
   - 验证水电燃气表读数是否准确
   - 确认物品损坏评估是否合理

#### 退款计算相关问题
1. **智能兜底失败**
   - 检查押金账单是否存在
   - 验证押金金额是否正确
   - 确认退款金额计算逻辑

2. **微信退款失败**
   - 检查微信支付配置
   - 验证账单交易号是否正确
   - 确认退款金额是否超过限制

#### 按日精算退租租金相关问题
1. **计算结果不准确**
   - 检查合同月租金是否正确
   - 验证计划退租日期格式
   - 确认账单周期计算是否正确

2. **接口调用失败**
   - 检查网络连接是否正常
   - 验证合同ID和日期参数
   - 确认后端服务是否可用

3. **精度计算错误**
   - 检查日租金计算精度
   - 验证入住天数计算逻辑
   - 确认四种场景判断正确性

#### 租户姓名过滤相关问题
1. **搜索结果不准确**
   - 检查租户姓名输入是否正确
   - 验证合同快照是否完整
   - 确认模糊搜索逻辑

2. **搜索性能问题**
   - 检查数据库索引是否正常
   - 验证搜索条件组合
   - 确认缓存机制是否生效

3. **合同快照失效**
